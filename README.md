# ResuMatch AI

ResuMatch AI analyzes a resume against a job description, identifies matching skills and skill gaps, and provides improvement suggestions.

## Features
- Upload a resume and paste a job description
- Extract and compare skills
- Show matching skills and missing skills
- Provide AI-powered career guidance

## Tech Stack
- Python, FastAPI
- React, Vite
- Groq API
